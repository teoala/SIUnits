# SIUnits

University project developed for the **Programming Languages** course
of the Bachelor's Degree in Computer Science at the
**University of Milano-Bicocca**.

SIUnits is a system for representing and manipulating physical
quantities and SI (International System of Units) units.

The project was implemented in both **Prolog** and **Common Lisp**,
exploring different programming paradigms for symbolic manipulation.

## Features

- Representation of SI base and derived units
- SI prefix management
- Unit normalization
- Conversion between compatible units
- Support for unit exponents
- Arithmetic operations between physical quantities
- Canonical representation of physical dimensions

## Implementations

### Prolog

The Prolog implementation uses logic programming techniques to
represent units, prefixes and relationships between physical dimensions.

### Common Lisp

The Common Lisp implementation provides equivalent functionality
using symbolic manipulation and list-based data structures.

## Technologies

- Common Lisp
